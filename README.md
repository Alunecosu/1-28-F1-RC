# 1:28 RC Car

> Work in progress.

A 1:28 scale remote-controlled car. I made this inspired by Tamiya's bigger RC car.

## Why I made it

I have a 1:10 scale RC F1 but the road on my street isn't smooth enoguh for it, so I decided to make a small and fast F1 rc car at 1:28 scale, I also tried to keep it budget friendly.

## How to use it

After wiring up everything and flashing the ESP32 S3 you will connect to the ESP32 S3 wifi with the password "12345678" and go on this link { http://192.168.4.1 } to connect and drive,

## Wiring

    GPIO 4  -> steering servo signal
    GPIO 5  -> ESC signal
    GND     -> ESC ground + servo ground (all grounds must be common)
    ESC BEC 5V -> ESP32-S3 "5V" pin and servo power
    (Do not connect USB and the ESC 5V to the ESP32 at the same time.)

## Assembly

1. Prepare the printed or manufactured parts.
2. Assemble the chassis and drivetrain.
3. Install the motor, steering mechanism, and wheels.
4. Secure the electronics and battery using the mounts [ the ESC uses double sided tape I had to do this in order to save height space :(  ]
5. Connect the electronics according to the wiring diagram.

## Firmware and flashing

1:28 RC car - ESP32-S3 receiver + phone web controller
  ------------------------------------------------------

- Step 1:
	Install Arduino program.

- Step 2:
  	Libraries to install (Arduino IDE > Library Manager):
    		- "WebSockets" by Markus Sattler
    		- "ESP32Servo" by Kevin Harrington
  	Board: "ESP32S3 Dev Module" (esp32 by Espressif, board package 3.x or 2.x)

- Step 3:
	Download and open the "rc_car_1_28.ino" from \firmware and connect the ESP32 S3 with a USB C to your pc.

- Step 4: 
	Flash the code you downloaded on the ESP32 S3 and you are good to go.

How it works:
    
	- The ESP32-S3 makes its own WiFi network (no router, no internet, no domain).
	
    - It also hosts the controller web page (inside this file).
	
    - Phone connects to the WiFi, opens http://192.168.4.1 and drives the car.
	
    - Car starts "killed" after every power-up. Tap "Re-arm" on the phone to drive.
